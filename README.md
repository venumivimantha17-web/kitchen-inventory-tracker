# Kitchen Inventory Tracker

A beginner-friendly Python project that demonstrates the fundamentals of functions and variable scope through a simple kitchen inventory tracker.

## Project Overview

This project simulates a kitchen inventory system where you can:

- Check the available kitchen ingredients
- Use eggs from the inventory
- Check whether enough eggs are available
- Make a fried egg
- Update the available egg count
- Practice local and global variable scope

## Concepts Practiced

- Python variables
- Functions
- Function parameters and arguments
- Local and global scope
- Name shadowing
- `if` / `else` statements
- Comparison operators
- `return` statements
- Variable reassignment
- F-strings
- Function calls
